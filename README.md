# 💰 Kişisel Bütçe Takip Sistemi (Budget Tracker)

JavaFX ve SQLite kullanılarak geliştirilmiş, harcamalarınızı kolayca yönetmenizi sağlayan masaüstü uygulaması.

## ✨ Özellikler
* **Harcama Yönetimi:** Harcamalarınızı ekleyebilir, silebilir ve listeleyebilirsiniz.
* **Tarih Desteği:** Harcamalar otomatik olarak işlem tarihiyle kaydedilir.
* **Filtreleme:** Ay bazlı filtreleme ile hangi ay ne kadar harcadığınızı görün.
* **Excel Raporu:** Mevcut harcamalarınızı tek tıkla `.xlsx` formatında dışa aktarın.
* **Veritabanı:** Verileriniz yerel SQLite veritabanında güvenle saklanır.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** Java 17+
* **Arayüz:** JavaFX (FXML)
* **Veritabanı:** SQLite
* **Bağımlılık Yönetimi:** Maven
* **Kütüphaneler:** Apache POI (Excel işlemleri için)

## 🚀 Nasıl Çalıştırılır?
1. Bu depoyu klonlayın veya indirin.
2. Maven bağımlılıklarını yükleyin.
3. `mvn javafx:run` komutu ile uygulamayı başlatın.
